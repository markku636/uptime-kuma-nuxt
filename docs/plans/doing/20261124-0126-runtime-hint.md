## 三、架構與關鍵決策

### 1. 新增一個共用提示元件 `components/common/RuntimeHint.vue`

- 外觀：固定 16×16 的 `UIcon name="i-heroicons-information-circle"`，包在 `<button type="button">` 內，`class="inline-flex shrink-0 align-middle"`，附 `aria-label`（例如 `What is the API?`）。
- 提示內容用 `UTooltip`（Nuxt UI 既有元件，浮層定位，**不參與排版**），`side="top"`、`:ui` 用現有深色／淺色 CSS 變數，不寫死顏色。
- 三種內容由 prop `kind` 決定：`api`／`worker`／`slots`。
- **按需載入**：只在 tooltip 開啟（hover／focus／click）時呼叫 API；關掉不自動輪詢。避免 Dashboard／Monitor 每次進頁都多一個請求，也避免資料還沒回來時文字長度變化造成位移。
- 載入中在 tooltip 內顯示固定高度的 `Explanation…`（不影響頁面排版）；失敗或 403 時退回通用說明，並在 pod 清單處顯示 `Pod names require platform administrator permission.`
- 不新增 i18n key：這三頁都是英文硬編碼文字，提示也直接寫英文，與現況一致。

### 2. 新增 `composables/useRuntimeHint.ts`

- `load()`：`$fetch<{ data: Runtime }>('/api/v1/nodes/runtime')`，只取提示需要的欄位。
- 複用 `podName(row)` 邏輯（`host || instanceId.slice(0, 8)`，與 `WorkerRuntime.vue:75-77` 一致）。
- 將 running instances 分成 `api`（role 為 api/all）與 `worker`（worker/all），與後端 `servesApi`／`runsChecks` 判定一致。
- 快取結果 10 秒（與 WorkerRuntime 的 `REFRESH_MS` 一致），避免同一頁多個 ⓘ 重複打 API。
- 失敗時不 throw，回傳 `{ pods: [], available: false }`，由元件顯示降級文字。

### 3. 提示文案（英文，最終版本）

- **API**：`The API serves the web UI, REST API and live updates. It never runs checks. Checks are pulled from the shared PostgreSQL queue by workers.` + `Pods: {names}`。
- **Worker**：`A worker pulls due checks from the shared PostgreSQL queue and runs them. Each worker has a fixed number of check slots; one slot is occupied per check until it finishes.` + `Pods: {names}`。
- **Slots in use**：`Checks currently running divided by the total check slots across all workers (for example 0/64). A higher value means more checks are running at the same time; 0 means no check is executing right now.`

### 4. 放置位置（精確）

| 檔案 | 位置 | 做法 |
| --- | --- | --- |
| `components/settings/WorkerRuntime.vue` | `:120` API label、`:134` Workers label、`:144` `Check slots in use`、`:153` 表格 `Slots in use` 欄 | 在文字旁插入 `<RuntimeHint kind="..." />`；原本 `flow-note` 與數值不動 |
| `pages/dashboard/index.vue` | `:3` `<h1>Monitor overview</h1>` | 改成 flex 容器，h1 後接一個 `RuntimeHint`（kind 可用 `api`，tooltip 內同時說明 API／Worker／Slots） |
| `pages/monitors/index.vue` | `:5` `<h1>Monitors</h1>` | 同上 |

Dashboard／Monitor 用單一 `kind="overview"` 提示，內容同時包含三個名詞與 Pod 清單，避免標題旁擠三個圖示。
